# Install, Uninstall, And Reinstall Test Matrix

Status: canonical lifecycle scenario catalog

Tracking issues: [#3](https://github.com/cloudbossdev/pagemaker365-installer/issues/3), [#4](https://github.com/cloudbossdev/pagemaker365-installer/issues/4), and [#10](https://github.com/cloudbossdev/pagemaker365-installer/issues/10)

Scenario status meanings:

- `Automated`: deterministic behavior has automated coverage; live evidence may still be required.
- `Partial`: some behavior is covered, but required negative-path or live evidence is incomplete.
- `Planned`: the product contract or test does not yet exist.

## Required Sandbox

- Dedicated CloudBoss test subscription, tenant, resource group, and portal environment.
- Customer install packages generated by the staging control plane.
- Disposable resource names, including a new Key Vault name for every reinstall package.
- Accounts capable of Azure deployment and removal plus Microsoft Graph validation.

## Evidence Assertions

Every scenario must confirm:

- No access token, secret, connection string, raw provider response, or document content appears in evidence.
- Preview and execution identify the same package, subscription, resource group, and inventory.
- Removed, retained, skipped, blocked, and failed items are explicit.
- Portal lifecycle and local evidence agree after queued callbacks are delivered.
- No customer SharePoint content or unrelated Azure resource changes.
